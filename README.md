# Portofolio — Mochamad Ramdhan

Website portofolio bergaya **Liquid Glass** (terinspirasi bahasa desain iOS).
Pure HTML + CSS + JavaScript, tanpa build step.

- `index.html` — struktur halaman
- `styles.css` — material liquid glass, tema gelap/terang, layout responsif (desktop & iPhone)
- `script.js` — latar silk animasi, highlight specular mengikuti kursor, nav/tab bar cair, filter proyek, sheet kontak
- `assets/portrait.webp` — foto profil

Deploy otomatis ke GitHub Pages lewat `.github/workflows/pages.yml`.

Jalankan lokal: buka `index.html` di browser, atau `python3 -m http.server`.
